# A deliberately bounded scenario

SC01: review an in-mission aerobic-capacity comparison

| Context | Specified position |
| --- | --- |
| User and setting | One simulated crew member in a long-duration deep-space transit example. No real mission, vehicle, astronaut or flight device is claimed. |
| Acquisition | A versioned replay adapter submits a completed assessment result. The replay is automated after start; it is not a live sensor feed. |
| Comparison | A reviewed personal pre-mission baseline and comparable in-mission assessment, with quantity, method and units explicitly identified. |
| Onboard action | Crew requests an assigned onboard review and records context. A qualified, authorized reviewer would determine any clinical next step. |
| Follow-up | A named owner records a disposition or an unresolved task with a due condition. The request does not itself mean care was delivered. |
| Earth handoff | Optional purpose-limited packet; delayed transfer, application receipt and clinical review are separate events. |

## Scope that must stay visible

This comparison is not a cardiac-event predictor, treatment recommendation or EVA clearance. Immune, bone, behavioral and other unmeasured domains remain Not assessed. One narrow episode is intended to test the software loop; it does not demonstrate comprehensive health monitoring or clinical benefit.

Direct and indirect assessment methods are possible in the source standard, but method equivalence is not automatic. An ordinary exercise oxygen-use sample, a heart-rate value or an unqualified wearable estimate cannot be relabeled as VO2max.

Current action content is a support workflow proposal. A health reviewer must approve measurement applicability, review language and the allowed next step before it can be presented as medically reviewed.
