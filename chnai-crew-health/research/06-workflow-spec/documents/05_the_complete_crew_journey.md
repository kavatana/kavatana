# The complete crew journey

A small number of deliberate decisions, with the routine work automated.

| Step | Automatic work | Crew or reviewer decision |
| --- | --- | --- |
| 1. Receive | Save source and ingest-job identity; account for every submitted record. | No manual transcription required for a valid replay. |
| 2. Qualify | Check quantity, units, identity, baseline, method, time and release. | Resolve a flagged gap; never guess missing clinical context. |
| 3. Compare | Calculate exact fraction and record all input revisions. | Inspect the result and its source when needed. |
| 4. Explain | Prepare a deterministic explanation; optional validated AI wording. | Read what changed and what remains unknown. |
| 5. Request review | Save an allowed support request and follow-up responsibility. | Crew chooses Request onboard review or records a reason to defer. |
| 6. Review | Show the same evidence to the assigned, permitted role. | Record disposition; choose a reviewed next step if available. |
| 7. Handoff | Prepare only authorized fields and retry released packets. | A permitted human approves the exact recipient, purpose and payload. |
| 8. Follow up | Keep unresolved work visible after restart or interruption. | Assigned actor records outcome; closure never means automatic recovery. |

If the assigned onboard reviewer is unavailable, the episode stays unresolved with an explicit next actor. Queuing a ground message must not be shown as receiving care. This prototype is not an emergency-response system.

The first demonstration should show steps 1-5 completing with Earth disconnected, followed by a separately labeled handoff and follow-up sequence. It must not depend on a ground reply to save or display the onboard result.
