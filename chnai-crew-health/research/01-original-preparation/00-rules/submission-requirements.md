# What must be submitted

From the 2025 Project Submission Guide. The 2026 guide is published on **13 November**;
check every line against it that evening.

## The project page

Everything is entered on the team's project page on spaceappschallenge.org. Submission
opens Saturday 14 November at 9:00 AM and closes Sunday 15 November at 11:59 PM.

| Field | What goes in it | Notes |
| --- | --- | --- |
| Project Name | A short, memorable name | Not the team name |
| High-Level Project Summary | A few sentences: what it is, how it answers the challenge, why it matters | Many judges read only this |
| Link to Project Demo | A video of **at most 30 seconds**, or a deck of **at most 7 slides** including the title | Over the limit means ineligible. English subtitles on video. Public link, no login |
| Link to Final Project | The running product and the code | Public, no login |
| Detailed Project Description | What it does, how it works, benefits, tools and languages used, what is next | Write for a judge with five minutes |
| NASA Data | Each NASA dataset or resource used, and how | Required for any Global Award |
| Space Agency Partner & Other Data | Every other source, including open-source libraries | List them all |
| Use of Artificial Intelligence | Which AI tools were used and for what | AI images and video carry a visible "AI-generated" mark |
| Verification boxes | Confirmations the team ticks | Read them before ticking |

## Before pressing submit

- [ ] Every member is on the team's Members tab, and registered for Phnom Penh.
- [ ] The demo opens in a private browser window with no sign-in.
- [ ] The final project opens in a private browser window with no sign-in.
- [ ] The video is 30 seconds or less, or the deck is 7 slides or fewer.
- [ ] The repository is public and has a licence file.
- [ ] Every data source and library is listed with a link.
- [ ] AI use is stated. AI images carry the mark.
- [ ] No NASA logo or insignia anywhere in the team's own material.
- [ ] No personal data of real people. Sample crew data is labelled as simulated.
- [ ] No product advertising.
- [ ] Submitted well before 11:59 PM. Aim for 9:00 PM.

## The two deadlines on Sunday

1. **2:30 PM, Phnom Penh:** the pitch submission for local judging. On time earns a bonus point.
2. **11:59 PM, global:** the project page. The organisers send reminders from 10:00 PM.

The hours between 5:30 PM and 11:59 PM are for improving the project page, which is what
the global judges read.
