## First development session

Read the context, inspect the current checkout, install the documented dependencies if absent and run the existing tests. Exercise the complete local path on a fresh fictional database. Record actual browser/host measurements. Fix the highest-impact reproducible defect and repeat the affected checks. Update the current-state record with exactly what changed; leave untested cases untested.

If the UI passes, make a focused visual iteration using the existing task and source evidence: clearer current task, input freshness/quality, responsible reviewer, exact sharing preview and communication state. Compare before/after at the same viewport. Do not redesign every page or change frameworks just to produce a different screenshot.

## Data expansion method

For each candidate family, answer: which user decision does it support; is it public research, environment context or synthetic replay; what license/access applies; what raw structure/time/units/method/identity are present; what uncertainty must be retained; what query/UI needs it; and what proves its adapter works? Retain immutable originals and a manifest. A checked parser, deterministic sample replay and explicit unsupported states are useful even when no flight API exists.

The catalog's 6,532 remote file rows and 119 study entries are discovery metadata. The 20-family allocation is a prioritization map, not a mandate to ingest every file or train a model. Never join research subjects to fictional crew, derive diagnoses from a small cohort, or interpret ambient radiation as personal dosimeter measurements without evidence.

## Decisions deliberately deferred

Framework migration; ORM adoption; separate high-throughput analytical store; multi-service deployment; new device protocols; model artifact/fine-tuning; 3D visualization; production identity/encryption/retention policy; Internet API deployment. Revisit each when its workload, source access, safety boundary and measured benefit justify the complexity.

An eventual spatial scenario lab must reuse `packages/domain/src/simulation.mjs` and the same expected-state checks. A new presentation layer is not independent medical evidence.
